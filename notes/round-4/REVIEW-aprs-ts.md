2. Medium. The position builder keeps the last altitude setter, and recipe.mjs:265-284 makes up `value-given-twice` itself, unmarked. The vectors rule ("One quantity, one value"): a setter replaces its quantity (last call wins on a builder); value-given-twice applies when ONE input carries both units (a recipe or a single call given both). So the tool-made refusal is legitimate for a recipe, but it must be marked `"via":"tool"`, and the size check must be the library's own on each single-unit build. Check the README rule and make the tool follow it exactly.
