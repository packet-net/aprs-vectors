Reviewer findings for aprs-py (verdict: merge after fixes). Fix all defects; take suggestions 3 to 7.
D1 (written bytes a user cannot read back). src/pdn_aprs/packet.py:129 `_read_back_tnc2_header` parses with third_party=self.third_party, so an inner packet's header written as a standalone line is read back under the relaxed third-party header rules. Repro: p = decode_tnc2(b"N0CALL>APRS:}a b>APRS,A*,B:>hi").data.packet; p.to_tnc2() returns b'a b>APRS,A*,B:>hi' and decode_tnc2 of that raises HeaderError invalid-address; same with source `S;C`; inner path `qAR,X` reads back with a q_construct the held packet does not have. Fix: read back with third_party=False, as a user's decode_tnc2 would, and refuse with the code the vectors rule at the new pin names for it.
D2. Mic-E /A= exactness not enforced on public data (_readback.py:250, encode.py:1362): MicEReport(altitude_feet=100.3, altitude_in_comment=True, ...) writes /A=000100. A /A= is allowed only where it holds the value exactly; require _near_whole even when altitude_in_comment is set.
S3. Make __str__ and __repr__ total: they show the header as held, with no read-back and no exception; refusals belong to to_tnc2, header, to_ax25, to_kiss only. README says which calls can raise EncodeError.
S4. BuilderAltitude (a private float subclass) leaks through Packet.data: replace(pk.data, altitude_feet=1000.0) == pk.data is True yet the two encode differently, and it survives pickle. Remove the subclass: the built packet's data holds the altitude as given as a plain float, and the builder passes "try the Mic-E bytes first" to the encoder by a private argument, never by a mark on a value the caller can see.
S5. CR or LF inside the information field written as a line: follow the vectors rule at the new pin. Document that Packet(...) built by hand has its info written as held.
S6. Builder path stars (encode.py:2056): p.rstrip("*") accepts `WIDE1-1**` as used WIDE1-1; exactly one trailing `*` marks a used entry, anything else is invalid-address.
S7. CHANGELOG line 9 names removed private helpers.
Test gaps: these mutations survive the whole suite; add a targeted test for each: dropping "a field given is not in the decode" (_readback.py:94); allowing any info diagnostic (_readback.py:64); allowing any read-back speed (not only Mic-E 0); also strengthen the thin ones (inner diagnostics, warnings, tolerance, compression type).
